# WAC_DS — Python & Pandas for Data Science

> Jupyter notebooks covering Python fundamentals and data manipulation with pandas.
> دفاتر Jupyter لأساسيات Python ومعالجة البيانات باستخدام pandas.

## Notebooks

| Notebook | Topic |
|---|---|
| [`python_objects.ipynb`](notebook/python_objects.ipynb) | Python basics: loops, functions and small exercises |
| [`panda.ipynb`](notebook/panda.ipynb) | pandas: reading CSV, JSON and SQLite (`read_sql_query`), selecting and filtering data |

## Datasets

| File | Description |
|---|---|
| `dataset/IMDB-Movie-Data.csv` | ~1,000 IMDB movies: title, genre, director, year, rating, revenue |
| `dataset/purchases.csv` / `.json` | Small sample table for pandas I/O |
| `dataset/database.db` | SQLite database used to demonstrate `read_sql` |
